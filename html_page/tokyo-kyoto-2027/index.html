一天一天的行程

每張卡都是可以獨立放進旅程的一整天

一定要去動漫・推活
01

東京・北區／池袋

《鬼滅之刃》推活與池袋動漫日

  1. 瀧野川八幡神社
  2. 池袋
  3. animate 池袋總店
  4. 乙女路
  • 09:00 先到瀧野川八幡神社參拜、拍照與留御朱印時間；可用胡蝶忍推活／聖地巡禮角度安排。
  • 11:00 前往池袋，在 Sunshine City 周邊用餐並逛扭蛋、角色商店。
  • 13:30 起留至少兩至三小時給 animate 池袋總店，再走乙女路與周邊動漫店。
  • 晚上留在池袋吃飯，避免再跨區趕行程。

兩個動漫二次元必去點排在同一天；神社社務時間與限定御朱印請出發前確認。

一定要去蠟筆小新
02

埼玉・春日部

蠟筆小新春日部一日巡禮

  1. 春日部車站
  2. ぷらっとかすかべ
  3. 市區散步
  4. 龍 Q 館候選
  • 上午抵達春日部車站，先找車站內外的小新裝飾與拍照點。
  • 到春日部資訊發信館「ぷらっとかすかべ」取得官方繁體中文散步地圖。
  • 依官方地圖走訪當期展示、紀念物與商品點，中途安排春日部午餐。
  • 若預約與交通時間合適，下午加入首都圈外郭放水路／龍 Q 館的小新像；否則留在市中心慢慢巡禮。

春日部店家與展示可能調整，2027 年以市政府最新版「蠟筆小新春日部散步地圖」為準。

一定要去神社・東京初訪
03

東京・飯田橋／丸之內

東京大神宮與東京市中心

  1. 東京大神宮
  2. 神樂坂
  3. 皇居外苑
  4. 東京車站
  • 09:00 前往東京大神宮參拜，預留御守、御神籤與御朱印時間。
  • 步行到神樂坂散步、吃午餐，感受巷弄與老街氣氛。
  • 下午到皇居外苑或東御苑；若遇休園日，改走丸之內建築與車站周邊。
  • 傍晚拍東京車站夜景，再到銀座或有樂町吃晚餐。

東京大神宮是本日必去核心；御朱印受理時間通常短於一般參拜時間。

花火四選一和服・東京
04

方案 A・東京東區

淺草和服攝影＋足立花火

  1. 淺草租和服
  2. 雷門・淺草寺
  3. 隅田公園
  4. 足立花火
  • 09:00 在淺草完成和服著裝，早上先拍雷門、仲見世與淺草寺。
  • 中午走到隅田公園淺草側拍河岸景色，提早吃午餐並補充水分。
  • 15:00 前依方案歸還和服；若希望穿去花火，必須預約晚歸或隔日歸還方案。
  • 16:30 前往北千住／荒川河川敷，先吃簡單晚餐、確認觀賞區，晚上看花火。

2027 日期未公告；足立花火近年安排在五月底且遇惡劣天候不順延，須保留備案。

花火四選一和服・東京
05

方案 B・東京中央／台場

日枝神社和服攝影＋STAR ISLAND

  1. 和服著裝
  2. 日枝神社
  3. 赤坂
  4. 御台場海濱公園
  • 09:00 完成和服著裝，前往日枝神社，以鳥居、石階與境內作主要拍攝場景。
  • 中午在赤坂用餐；視體力補拍東京車站或銀座街景。
  • 15:00 前歸還和服並換成方便久站的衣物，再經新橋前往御台場。
  • 提早依票種進場，晚上欣賞 STAR ISLAND 音樂與花火演出。

這是售票型演出。CSV 的 5/23 為既有年度資料，2027 是否舉辦及日期須等待官方公告。

花火四選一和服・關西
06

方案 C・兵庫

姬路和服攝影＋相生佩隆祭海上花火

  1. 京都
  2. 姬路和服
  3. 姬路城
  4. 相生灣
  • 早上從京都前往姬路，在姬路站周邊預約和服著裝。
  • 以姬路城、好古園外圍與城下町為拍照主線，午餐也留在姬路。
  • 14:30 左右歸還和服，再搭 JR 前往相生，避開傍晚最擁擠時段。
  • 先完成觀賞區報到與晚餐，晚上欣賞相生灣海上花火，散場後再返回住宿地。

相生佩隆祭通常在五月最後一個週末；部分觀賞區需購票，2027 日期與回程末班車都要先確認。

花火四選一和服・京都
07

方案 D・京都／滋賀

祇園和服攝影＋Symphonic Starmine

  1. 祇園白川
  2. 二寧坂
  3. 產寧坂
  4. 烏丸半島
  • 09:00 在祇園完成和服著裝，趁早拍祇園白川與巽橋。
  • 接著前往二寧坂、產寧坂拍照，中午前回到祇園用餐。
  • 13:30 左右歸還和服，回住宿取保暖衣物，再前往滋賀草津的烏丸半島。
  • 依指定交通與票種入場，下午參加活動並留到晚上的音樂花火演出。

四個方案中地理動線最適合京都住宿；活動為全區售票制，2027 是否舉辦仍待公告。

第一次日本京都經典
08

京都・東南區

伏見稻荷、清水寺與祇園

  1. 伏見稻荷
  2. 清水寺
  3. 二寧坂
  4. 祇園
  • 清晨先走伏見稻荷大社與千本鳥居，避開主要人潮。
  • 中午前移動到清水寺，沿產寧坂、二寧坂一路慢慢下行。
  • 經八坂神社到祇園白川，傍晚在鴨川或先斗町用餐。

若已選方案 07，可縮短重複的二寧坂與祇園，把時間留給伏見稻荷。

第一次日本東京經典
09

東京・東區

淺草、上野與秋葉原

  1. 淺草寺
  2. 上野
  3. 阿美橫町
  4. 秋葉原
  • 早晨逛雷門、仲見世通與淺草寺，也可登淺草文化觀光中心看街景。
  • 下午在上野公園選一間博物館，或改逛阿美橫町。
  • 晚上到秋葉原，依興趣安排電器、模型、遊戲與動漫商店。

若選方案 04，淺草會重複，可把本日淺草改成東京晴空塔。

第一次日本東京經典
10

東京・西區

明治神宮、原宿、澀谷與新宿

  1. 明治神宮
  2. 原宿
  3. 澀谷
  4. 新宿
  • 上午先走明治神宮，再到原宿竹下通、表參道與 Cat Street。
  • 下午前往澀谷十字路口與商場；展望台若想去需事先預約。
  • 晚上到新宿看夜景、吃晚餐，依喜好選擇歌舞伎町或較安靜的都廳周邊。

若選方案 05，明治神宮可改為新宿御苑或留更多時間逛澀谷。

推薦的十四天行程表

所有必去點都已排入；花火先保留一個選擇日

我的優先推薦：若 2027 年日期能配合，選「方案 D：祇園和服＋Symphonic Starmine」，因為京都拍照後前往滋賀最順路。

若最後選東京的足立花火或 STAR ISLAND，把花火日移到東京住宿期間，並與第 12 或第 13 天互換即可。

日期住宿／區域主要行程安排理由與提醒
Day 01京都關西國際機場 → 京都車站 → 入住 → 車站周邊抵達日只排輕鬆散步，避免班機延誤影響預約。
Day 02京都東南伏見稻荷 → 清水寺 → 產寧坂／二寧坂 → 八坂神社 → 祇園第一次京都的核心路線，清晨先去伏見稻荷。
Day 03京都西區嵐山竹林 → 天龍寺 → 渡月橋 → 金閣寺早到嵐山；下午跨區去金閣寺，晚上不要再排遠程景點。
Day 04奈良奈良公園 → 東大寺 → 春日大社 → 奈良町從京都往返的一日經典行程，補足第一次日本的古都體驗。
Day 05京都中央二條城 → 京都御苑 → 錦市場 → 四條河原町／先斗町以室內、庭園與購物混排，讓步行量稍微下降。
Day 06宇治／伏見平等院 → 宇治川 → 茶街 → 伏見酒藏區作為京都近郊緩衝日，也能依體力改成自由活動。
Day 07京都／花火地點和服攝影＋方案 04–07 擇一＋晚上花火優先選方案 D；實際放在第幾天完全依 2027 官方日期調整。
Day 08東京京都 → 東京 → 入住 → 東京車站 → 丸之內 → 銀座跨城市移動日，行李多時可考慮宅配。
Day 09飯田橋／中央區東京大神宮 → 神樂坂 → 皇居外苑 → 東京車站夜景必去：東京大神宮；御朱印與授與所時間先確認。
Day 10北區／池袋瀧野川八幡神社 → Sunshine City → animate 池袋總店 → 乙女路必去：兩個動漫二次元地點合併成推活日。
Day 11春日部春日部車站 → 官方小新散步地圖路線 → 小新展示／商品點必去：完整保留一天給蠟筆小新巡禮。
Day 12東京東區淺草寺 → 隅田公園 → 上野／阿美橫町 → 秋葉原若花火方案已走過淺草，就把上午替換成晴空塔。
Day 13東京西區明治神宮 → 原宿 → 表參道 → 澀谷 → 新宿東京經典街區日；展望台與熱門餐廳提前預約。
Day 14東京 → 成田住宿附近採買 → 退房 → 成田國際機場依航班時間決定是否能排早上活動，至少保留完整機場交通時間。

花火活動不一定每年固定同一週；選定 2027 正式場次後，應先鎖定花火日，再把其餘行程依區域前後移動。

行前確認與資料來源

2027 正式公告發布後再完成最後排程

花火日期

CSV 內的五月日期先視為候選，不當成 2027 已確認日期。先確認舉辦、售票、雨天政策，再訂住宿與跨城車票。

和服歸還

一般租借店傍晚前歸還；若要穿去花火，必須預約晚歸或隔日歸還。長距離方案建議拍完先歸還再移動。

交通與散場

花火散場與末班車是關鍵。相生、琵琶湖方案需先確認回程；東京方案則提早決定車站與步行出口。
